# Cursor RTL

راست‌چین و فونت فارسی برای پرسش‌ها، پاسخ‌ها و کادر نوشتن چت Cursor. بلوک کد، diff، ترمینال و ویرایشگر کد چپ‌چین و monospace می‌مانند.

## نصب

```powershell
npm install
npm test
npm run package
cursor --install-extension cursor-rtl-0.1.2.vsix
```

بعد از نصب، افزونه در شروع Cursor وصله را روی `workbench.html` می‌گذارد. اگر Cursor در `Program Files` باشد، ویندوز یک‌بار اجازهٔ مدیر می‌خواهد. سپس Cursor را کامل ببندید و دوباره باز کنید. روشن و خاموش کردن و عوض کردن فونت بعد از آن، در همان نشست اعمال می‌شود.

## استفاده

- نوار وضعیت: `RTL: وزیرمتن` یا `RTL: خاموش`. کلیک، قابلیت را عوض می‌کند.
- پالت دستور (`Ctrl+Shift+P`):
  - `Cursor RTL: روشن یا خاموش کردن`
  - `Cursor RTL: انتخاب فونت چت`
  - `Cursor RTL: نصب دوباره بعد از آپدیت`
  - `Cursor RTL: برداشتن وصله`
- تنظیمات: `Cursor RTL`

فونت‌ها: وزیرمتن (پیش‌فرض)، وزیر، شبنم، ساحل، استعداد، Tahoma، یا نام یک فونت نصب‌شده.

برای فایل‌های `.md` دو چک‌باکس جدا هست: `Markdown Rtl` برای راست‌چین، و `Markdown Font` برای اعمال فونت انتخاب‌شده. خاموش کردن فونت، فونت قبلی ویرایشگر را برمی‌گرداند.

فونت‌های همراه افزونه زیر مجوز SIL Open Font License هستند. جزئیات در `media/OFL.txt` و `media/FONT-SOURCES.txt`.
